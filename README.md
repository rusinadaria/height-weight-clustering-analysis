# Кластеризация датасета роста и веса методом k-средних и иерархической кластеризации

## Описание проекта

В данном проекте проводится статистический анализ датасета роста и веса людей, а также выполняется кластеризация объектов с использованием методов машинного обучения:

* метода k-средних (K-means)
* иерархической кластеризации (Agglomerative Clustering)

Цель проекта — исследовать структуру данных и определить возможность автоматического разделения объектов на группы на основе роста и веса.

---

## Используемые данные

Файл:

```
weight-height.csv
```

Структура датасета:

| Поле   | Описание        |
| ------ | --------------- |
| Gender | пол человека    |
| Height | рост (в дюймах) |
| Weight | вес (в фунтах)  |

Размер датасета:

```
10000 записей
5000 мужчин
5000 женщин
```
